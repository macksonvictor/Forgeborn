# Forgeborn

Forgeborn is a pixel-art action RPG prototype about forging living warriors and fighting with them in arena battles.

The player does not simply choose a hero.

The player creates one.

## Core idea

Forge your body.  
Choose your weapon.  
Enter the arena.

Every warrior is forged.  
Every victory is earned.

## Project direction

Forgeborn is a separate game project born from the SpriteForge idea.

- SpriteForge = creative asset generation tool / engine
- Forgeborn = game that may use SpriteForge as its visual generation technology

## Current status

This repository currently contains the game design document and will later contain the first playable prototype.
